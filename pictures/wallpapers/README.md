# 📁 pictures/wallpapers —— 壁纸图库说明

本目录是仓库中的**壁纸/插画收藏目录**，目前收录 **16 张壁纸**（`.jpg` / `.png` / `.webp`），题材以《原神》（Genshin Impact）的角色「哥伦比娅 / Columbina（月神）」为主，另含 2 张来自 Wallhaven（神里绫华、希佩尔各 1 张）。

所有壁纸都按统一的命名公式重命名，**不打开图片也能从文件名快速知道 PID、氛围、场景、角色、姿势、分辨率与长宽比**。

## 一、命名规则（怎么读文件名）

每个文件名都遵循同一套结构：

```text
{PID}[角色/氛围][大场景](细节元素_姿势_表情)[分辨率][长宽比]
```

逐段拆解：

| 段                     | 含义                                                              | 示例                                               |
| ---------------------- | ----------------------------------------------------------------- | -------------------------------------------------- |
| `{PID}`                | 原图唯一 ID，用大括号包裹，放在最前，保证文件夹内可按数字顺序排列 | `{135818744}`、 `{x8qqzd}`                         |
| `[角色/氛围]`          | 第一组中括号：定基调，写画风/氛围/风格                            | `[唯美]`、 `[清冷]`、 `[软萌]`                     |
| `[大场景]`             | 第二组中括号：大场景/环境                                         | `[月夜水面]`、 `[蓝花楹花海]`、 `[雪景列车]`       |
| `(细节元素_姿势_表情)` | 小括号：角色与具体细节，用下划线分隔，优先“双字词/四字词”         | `(哥伦比娅_起舞_闭眼)`、 `(希佩尔_花朵_围裙_绿瞳)` |
| `[分辨率]`             | 图片实际像素尺寸（宽×高）                                         | `[4000x4000]`、 `[1920x1080]`                      |
| `[长宽比]`             | 简化后的宽高比，Windows 不允许半角冒号，故用全角冒号 `：`         | `[1:1]`、 `[16:9]`、 `[2:3]`                       |

### 为什么 PID 在最前？

- 壁纸文件夹最怕“中文文件名打乱排序”；
- `{135818744}` 这样的纯数字前缀可以保证按 `ls` / 资源管理器排序时严格按 ID 顺序排列；
- 找回原图、去 Pixiv 查看作者、比对是否有更高清版本都非常方便。

> **补充说明**：Wallhaven 的 PID 为字母开头（如 `{x8qqzd}`），按文件名排序时会自动排在所有纯数字 Pixiv 图片之后（因为数字 ASCII 码小于字母），恰好形成“Pixiv 在前，Wallhaven 在后”的自然分区，不影响整理逻辑。

### 几个例子

```text
{140368429}[唯美][虞美人花海](哥伦比娅_花海_凝视)[4000x4000][1:1]
```

- PID = `140368429`（原图是 Pixiv 插画《虞美人》）；
- 氛围=唯美；场景=虞美人花海；角色=哥伦比娅；细节=花海、凝视；分辨率为 4000×4000 正方形。

## 五、如何使用

1. **做桌面壁纸**：选 `16:9` / `9:5` 的横屏大图最合适；手机建议用 `2:3` / `5:6` 或正方形图。
2. **找原图 / 看作者**：表格里的「原图链接」可直达 Pixiv / Wallhaven 原页面（链接失效时用文件名里的 PID 拼 `https://www.pixiv.net/artworks/<ID>` 或 `https://wallhaven.cc/w/<ID>` 搜索）。
3. **去重 / 整理**：PID 在最前，按文件名排序即可直观看出是否有重复 ID，或同系列画作。
4. **接入仓库站点**：本目录已同步维护 `pictures/wallpapers/._info.json`；根目录 `share-file.json`、`share-file.cdn.json` 引用也已处理；新增/改名文件后记得同步更新，否则站点索引/共享链接可能失效。
5. **预览缩略图（可选）**：如果觉得只看文件名不够直观，可以考虑在本目录下生成一张 `preview.jpg`（壁纸缩略图拼贴），并在 README 中引用，方便快速浏览色彩与构图。

## 六、维护与新增壁纸规范

- 新增图片请沿用同一命名公式：`{PID}[角色/氛围][大场景](细节元素_姿势_表情)[分辨率][长宽比]`。
- PID 必须是原文件原有 ID：Pixiv 用数字 illust ID，Wallhaven 用短 ID，不要自造编号，便于反查原图.
- 分辨率 = 实际文件像素尺寸（可先用图片查看器看到），长宽比可四舍五入取常见值（1:1、2:3、3：4、16:9 等）。
- Windows 文件名**不能包含半角冒号 `:`**，所以比例统一使用全角冒号 `：`（如 `[16:9]`）；也不能包含 `\ / : * ? " < > |` 等保留字符。
- 标签尽量短：中括号用 2~6 字，小括号内用“双字词/四字词”，下划线分隔.
  具体可选词：
  - 氛围：透明感、厚涂、平涂、粉彩、水彩风、光效、赛博、科技感、唯美、清冷、空灵、软萌、氛围感.
    。
  - 环境/场景：草地、花海（紫藤/玫瑰/黄花/蓝花）、天空、星空、月夜、室内、列车、舞台、花园。
  - 服装饰品：白裙、蓝裙、蕾丝、芭蕾裙、长筒袜、白丝袜、蝴蝶结、围裙、头饰..\*\*
- **硬性约束**：氛围/场景中括号内 **禁止使用空格和英文单词**（通用缩写如 `MMD`、`3D` 除外），一律使用 2~4 个中文字符，保证命名整齐统一。
- 若拿到更高清版本或换页（`_p0` → `_p1`），建议把 `_pN` 保留在 PID 段内（如 `{135818744_p1}`），避免同 ID 不同页互相覆盖。
